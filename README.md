# 🌐 Personal Portfolio – Juan Esteban Rodríguez Aranda

Este repositorio contiene el desarrollo de mi portafolio personal, diseñado como carta de presentación profesional y como espacio para experimentar con tecnologías modernas de desarrollo web.

---

## 🚀 Enfoque del Proyecto

El objetivo principal de este portafolio es **unir la estética visual con la funcionalidad técnica**, creando un sitio que refleje tanto mis habilidades técnicas como mi visión de diseño.  

- **Diseño Responsivo:** Adaptación a diferentes tamaños de pantalla (desktop, tablet, mobile-first).  
- **Interactividad:** Implementación de componentes dinámicos como el menú hamburguesa y tarjetas (`cards`) con efectos hover.  
- **Escalabilidad:** Código estructurado para futuras ampliaciones (nuevas secciones, proyectos, artículos).  
- **Práctica Profesional:** Uso de estándares de la industria (HTML5, CSS3, Flexbox/Grid, responsive breakpoints comunes).  

---

## ⚙️ Estado Actual

Este proyecto se encuentra en **fase de construcción**:  
- El diseño y la arquitectura visual están en proceso de consolidación.  
- Varias secciones están planteadas (hero, cards, navbar), pero sujetas a iteración y mejora continua.  
- Actualmente el énfasis está en lograr **responsividad completa** y una **navegación fluida** en todos los dispositivos.
